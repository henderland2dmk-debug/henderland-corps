## ⚡ Getting Started

```bash
# Clone the repository
git clone https://github.com/henderland2dmk-debug/henderland-corps.git
cd henderland-corps

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
npm run start
```
